# Common Utilities

Common types, utilities, and helper functions used throughout Pyvider.

## Overview

The `pyvider.common` module provides shared utilities for:
- Type definitions and protocols
- Context management (provider, resource, operation contexts)
- Launch context detection
- Configuration management
- Encryption utilities
