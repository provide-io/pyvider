# Troubleshooting

This section provides solutions to common problems you may encounter when using `pyvider`.

## Common Issues

### "Provider not found" error

This error occurs when Terraform cannot find the provider binary. To fix this, make sure that the provider binary is in the correct directory and that the directory is in your `PATH`.

### "Invalid provider configuration" error

This error occurs when the provider configuration is invalid. To fix this, make sure that the provider configuration is correct and that all the required fields are set.

### "Resource not found" error

This error occurs when a resource cannot be found. To fix this, make sure that the resource exists and that you have the correct permissions to access it.

## Getting Help

If you are still having problems, you can get help by creating an issue on the GitHub repository. When you create an issue, please make sure to include the following:

-   A clear and descriptive title for the issue.
-   A detailed description of the problem.
-   Steps to reproduce the problem.
-   The version of `pyvider` you are using.
-   The version of Terraform you are using.
-   Any relevant logs or error messages.
