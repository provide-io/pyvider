# 🎉 Getting Started

This guide will help you get started with `pyvider`.

## 📦 Installation

To get started with Pyvider, you'll need to have Python 3.11 or later installed. You can install Pyvider using pip:

```bash
pip install pyvider
```

## 🚀 Quick Start

To create a new provider, you can use the `pyvider` command-line tool:

```bash
pyvider new my-provider
```

This will create a new directory called `my-provider` with a basic provider project structure. You can then start adding your own resources, data sources, and functions to the project.
