# Chapter 8: The Grand Tour - Creating the `jq` Components

Welcome, artisan, to the grand tour. In this chapter, we'll embark on a journey to create a real-world `pyvider` component from scratch. We'll build a `jq` function and a `jq` data source that can be used to query JSON data.

## 🗺️ The Destination

Our destination is a fully functional `jq` component that can be used to query JSON data in our Terraform configurations. We'll create a `jq` function that can be used to apply a `jq` filter to a JSON string, and a `jq` data source that can be used to read a JSON file and apply a `jq` filter to it.

## 🎒 What You'll Need

Before we begin, you'll need to have a good understanding of the following concepts:

-   The `pyvider` architecture
-   The `pyvider` schema
-   The `pyvider` developer guide

If you're not familiar with these concepts, I recommend that you review the previous chapters before proceeding.
