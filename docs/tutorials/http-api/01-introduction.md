# Chapter 9: The Oracle - The `http_api` Data Source

Welcome, seeker of knowledge, to the oracle's chamber. In this chapter, we'll learn how to consult the oracle and retrieve information from the web using the `http_api` data source.

## 🗺️ The Quest

Our quest is to create a data source that can make an HTTP GET request to a given URL and return the response body. This will allow us to fetch data from any API on the web and use it in our Terraform configurations.
