# Chapter 10: The Scribe - The `file_content` Resource

Welcome, scribe, to the scriptorium. In this chapter, we'll learn how to use the `file_content` resource to write our own stories and bring them to life.

## 🗺️ The Task

Our task is to create a resource that can manage the content of a file on the local filesystem. This will allow us to create, read, update, and delete files with Terraform.

## 🎒 What You'll Need

Before we begin, you'll need to have a good understanding of the following concepts:

-   The `pyvider` architecture
-   The `pyvider` schema
-   The `pyvider` developer guide

If you're not familiar with these concepts, I recommend that you review the previous chapters before proceeding.
