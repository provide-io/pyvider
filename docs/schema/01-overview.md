# 📜 Schema

This chapter provides a detailed overview of the `pyvider` schema.

## 🏛️ Overview

The `pyvider` schema is used to define the structure and constraints of your provider's resources, data sources, and functions. The schema is defined using a combination of Python types and `pyvider`'s own schema types.

The schema is hierarchical, with a root schema that contains a set of attributes and blocks. Attributes are used to define the simple values in your schema, while blocks are used to define the nested objects.
