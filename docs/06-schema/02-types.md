# 🔠 Types

This guide provides a reference for the `pyvider` schema types.

## 📄 Overview

`pyvider` provides a set of built-in types that you can use to define the attributes in your schema. These types correspond to the primitive types in Terraform.

## 🚀 Available Types

The following types are available:

-   `string`: A string of text.
-   `number`: A number.
-   `bool`: A boolean.
-   `list`: A list of values.
-   `map`: A map of key-value pairs.
-   `set`: A set of unique values.
-   `object`: a structured object with a nested schema
-   `tuple`: a structured list with a nested schema
-   `any`: any of the above types
