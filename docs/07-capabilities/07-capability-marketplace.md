# 🏪 Capability Marketplace

This guide provides a curated list of community-built capabilities that you can use in your `pyvider` provider.

## 📄 Overview

The `pyvider` community is constantly creating new and exciting capabilities that you can use to extend the functionality of your provider. This guide provides a curated list of some of the best capabilities that are available.

## 🚀 Available Capabilities

-   **[pyvider-auth0](https://github.com/example/pyvider-auth0):** A capability that adds support for Auth0 authentication.
-   **[pyvider-sentry](https://github.com/example/pyvider-sentry):** A capability that adds support for Sentry error reporting.
-   **[pyvider-datadog](https://github.com/example/pyvider-datadog):** A capability that adds support for Datadog monitoring.

If you've created a capability that you'd like to share with the community, please open a pull request to add it to this list.
